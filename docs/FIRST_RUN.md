# First-run setup

1. Clone CareerPilot and run `setup.bat`.
2. Accept the default user-data directory or use `CAREERPILOT_USER_DATA_ROOT`.
3. Choose a materials folder. Existing materials are not moved automatically.
4. If old local runtime data is detected, approve an import only after checking the migration report.
5. Run `Open CareerPilot.bat`.

The repository never needs a user email, phone, resume, application history or SMTP authorization code to start. SMTP credentials are stored separately in the current Windows user's DPAPI-protected CareerPilot secret store.
